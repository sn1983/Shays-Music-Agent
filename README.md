# 🎵 Music Nostalgia AI Agent

סוכן AI אוטונומי ששולח כל יום המלצה על שיר Pop/Rock מהעשורים 90's–2020's
לטלגרם (ואופציונלית גם לעמוד פייסבוק), עם תקציר בעברית בסגנון שדרן רדיו,
עובדות מעניינות ולינקים להאזנה.

> **רוצים להתחיל?** כל ההוראות — יצירת הבוט, חיבור לטלגרם האישי ותזמון יומי —
> נמצאות ב-**[docs/TELEGRAM_SETUP.md](docs/TELEGRAM_SETUP.md)**.
> לחיבור פייסבוק: **[docs/FACEBOOK_SETUP.md](docs/FACEBOOK_SETUP.md)**.
> להרצה על המחשב שלכם בלי Git: **[docs/LOCAL_RUN.md](docs/LOCAL_RUN.md)**.

## התחלה מהירה

```bash
pip install -r requirements.txt
cp .env.example .env          # מלאו CLAUDE_API_KEY, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID

python main.py test-telegram        # בדיקת חיבור לטלגרם
python main.py sync-subscribers     # קליטת נרשמים חדשים (/start)
python main.py subscribers          # מי רשום כרגע
python main.py test-facebook        # בדיקת חיבור לפייסבוק (אופציונלי)
python main.py run-once --dry-run   # הרצה יבשה
python main.py run-once             # שליחה אמיתית
python main.py schedule             # שליחה יומית ב-20:00
```

## איך זה עובד

```
                    ┌──────────────── SQLite ────────────────┐
                    │ מה כבר פורסם · אמנים · שנים · עשורים     │
                    └───────────────┬───────────────────────┘
                                    │  היסטוריה
                                    ▼
   selector.py  ──►  שלב 1: בחירת שיר  ──►  שלב 2: מחקר  ──►  formatter.py  ──┬──►  Telegram
   עשור יעד,          Claude, ללא כלים        Claude + חיפוש       תבנית ההודעה     │     sendPhoto / sendMessage
   חסימת אמנים                                 באינטרנט                             └──►  Facebook
   ושנים חוזרות                                                                            Graph API (אופציונלי)
```

1. **מדיניות הבחירה** (`music/selector.py`) — קוד, לא פרומפט. מחשבת את עשור היעד
   לפי הפער בין ההתפלגות בפועל ליעד (30/30/20/20), ומרכיבה רשימת אמנים, שנים ושירים חסומים.
2. **שלב הבחירה** (`ai/claude_client.py`) — Claude בוחר שיר תחת האילוצים האלה
   ומחזיר JSON מובנה.
3. **שלב המחקר** — Claude עם כלי החיפוש בצד השרת מאמת את השיר, אוסף לינקים
   ועובדות, וכותב את התקציר בעברית. שדה שלא אומת חוזר כ-`null` במקום להיות מומצא.
4. **ולידציה** (`pipeline.py`) — כל בחירה נבדקת מול מסד הנתונים, מול הז'אנרים
   החסומים ומול עשור היעד. בחירה שנפסלה חוזרת למודל עם הסיבה, עד 4 ניסיונות.
5. **פרסום ותיעוד** — ההודעה נשלחת **לכל המנויים**, ואם פייסבוק מופעל היא ממוזגת גם לשם
   (כשלון בפייסבוק לא מפיל את ההרצה — טלגרם כבר יצא). השיר נרשם ל-SQLite כדי שלא יחזור.

## מנויים

הבוט פתוח לכל מי שישלח לו `/start`. אין צורך להגדיר chat_id לכל אדם.

| פקודה בטלגרם | מה קורה |
|---|---|
| `/start` | נרשם, ומקבל מיד הודעת ברוכים הבאים שכוללת **באיזו שעה יגיע העדכון היומי** |
| `/stop` | מוסר מהתפוצה ומפסיק לקבל עדכונים. `/start` יחזיר אותו |
| `/status` | האם המנוי פעיל ומתי מגיע השיר הבא |
| `/help` | מה הבוט עושה ורשימת הפקודות |

- **מי שכבר היה רשום נשאר רשום** — ה-`TELEGRAM_CHAT_ID` מההגדרות נכנס אוטומטית לרשימה.
- **מי שחוסם את הבוט מוסר אוטומטית** מהרשימה, כדי לא לנסות אליו שוב כל יום.
- **אם אף אחד לא רשום, ההרצה נעצרת מוקדם** ולא משלמת על בחירה ומחקר.

**איפה רואים מי רשום:** הקובץ [`storage/subscribers.md`](storage/subscribers.md)
מתעדכן אוטומטית בכל הרצה וניתן לפתיחה ישירות ב-GitHub (גם מהטלפון). לרשימה
המלאה עם המזהים המלאים: `python main.py subscribers`.

איך הבוט שומע נרשמים חדשים — שתי אפשרויות:

| מצב | פקודה | זמן תגובה |
|---|---|---|
| GitHub Actions (ברירת מחדל) | `sync-subscribers` רץ כל 15 דקות | עד ~15 דקות |
| מכונה שרצה תמיד | `python main.py bot` | מיידי |

## כללי הבחירה

| כלל | ערך ברירת מחדל | איפה משנים |
|---|---|---|
| חלוקת עשורים | 90's 30% · 2000's 30% · 2010's 20% · 2020's 20% | `DECADE_WEIGHTS` ב-`music/selector.py` |
| אמן לא חוזר | 30 פרסומים | `ARTIST_COOLDOWN_POSTS` |
| שנת יציאה לא חוזרת | 10 פרסומים | `YEAR_COOLDOWN_POSTS` |
| ז'אנרים חסומים | Rap, Metal, Hardcore, Jazz, Classical | `BLOCKED_GENRES` |
| שיר לא חוזר | לצמיתות | טבלת `published_songs` |

## עמידות בתקלות

| תקלה | מה קורה |
|---|---|
| ה-API של Claude עמוס (`529`) | ניסיון חוזר אחרי 20, 60 ו-120 שניות, ואז אותה בקשה על מודל הגיבוי (`CLAUDE_FALLBACK_MODEL`) |
| קריאה ארוכה במיוחד | כל הקריאות מוזרמות (streaming), כך שמחקר ארוך לא נחתך ב-timeout |
| שעה לא מתאימה או סוד חסר | הרצה שאין לה מה לעשות יוצאת בשקט עם קוד 0, בלי לדרוש מפתחות |
| GitHub מאחר בתזמון (שגרתי) | ארבע משבצות cron, והפרסום קורה בראשונה שנוחתת אחרי 20:00 |
| פייסבוק נכשל | נרשם ללוג, טלגרם כבר יצא, ההרצה נחשבת מוצלחת |
| ההרצה בענן נכשלה | נשלחת התראה לטלגרם עם קישור ללוג |
