# 📘 מדריך חיבור לפייסבוק (Phase 2)

אחרי שהסוכן כבר שולח לטלגרם, אפשר להוסיף פרסום אוטומטי גם לעמוד פייסבוק —
אותו שיר, אותה שעה, בלי עבודה נוספת.

**זמן משוער: 20 דקות.** רוב הזמן הולך על הגדרות באתר של Meta, לא על קוד.

---

## לפני שמתחילים — שני דברים שחשוב לדעת

1. **חייבים עמוד (Page), לא פרופיל אישי.** ה-API של פייסבוק לא מאפשר פרסום
   אוטומטי לפרופיל פרטי — רק לעמוד. אם אין לכם עמוד, צרו אחד ב-
   <https://www.facebook.com/pages/create> (חינם, לוקח דקה).
2. **צריך אפליקציה ב-Meta for Developers.** זה רק "מיכל" טכני שמנפיק את הטוקן;
   אתם לא מפרסמים אותה ואף אחד לא רואה אותה.

---

## שלב 1 — יצירת אפליקציה

1. היכנסו ל-<https://developers.facebook.com/apps>
2. **Create App**
3. בשאלה **What do you want your app to do?** בחרו **Other**
4. בסוג האפליקציה בחרו **Business**
5. תנו שם (למשל `Shay Music Agent`) ולחצו **Create App**

---

## שלב 2 — מציאת ה-PAGE_ID

הדרך הפשוטה: היכנסו לעמוד הפייסבוק שלכם → **About** → גללו למטה, ה-**Page ID**
מופיע שם. זה מספר ארוך, למשל `102938475610293`.

לחלופין, אחרי שלב 3 אפשר להריץ ב-Graph API Explorer את הבקשה `me/accounts`
והיא תחזיר את כל העמודים שלכם יחד עם ה-id של כל אחד.

---

## שלב 3 — קבלת Access Token

זה החלק המסובך היחיד. עקבו בדיוק.

1. פתחו את **Graph API Explorer**: <https://developers.facebook.com/tools/explorer>
2. בצד ימין למעלה, תחת **Meta App**, בחרו את האפליקציה שיצרתם.
3. תחת **User or Page** בחרו **Get Page Access Token** ואשרו את העמוד שלכם.
4. תחת **Permissions** הוסיפו את שתי ההרשאות הבאות:

   ```
   pages_manage_posts
   pages_read_engagement
   ```

5. לחצו **Generate Access Token** ואשרו את החלונות שנפתחים.
6. העתיקו את הטוקן שהתקבל.

### הארכת הטוקן ל-60 יום (חשוב!)

הטוקן משלב 3 תקף לשעה בלבד. כדי לקבל טוקן ארוך-טווח:

1. פתחו את **Access Token Debugger**: <https://developers.facebook.com/tools/debug/accesstoken>
2. הדביקו את הטוקן ולחצו **Debug**
3. לחצו **Extend Access Token** בתחתית העמוד
4. העתיקו את הטוקן החדש — **זה הטוקן שנכנס ל-`.env`**

בדקו שוב ב-Debugger שהטוקן החדש מציג:

- **Type:** Page
- **Expires:** Never (או תאריך בעוד כחודשיים)
- **Scopes:** כולל `pages_manage_posts`

> 💡 טוקן של עמוד שנוצר מטוקן משתמש ארוך-טווח בדרך כלל לא פג כלל. אם בכל זאת
> יפוג — תקבלו שגיאת `OAuthException` בלוגים, ותצטרכו לחזור על שלב 3.

> ⚠️ הטוקן הוא סיסמה לכל דבר. אל תשתפו אותו ואל תעלו אותו ל-GitHub.

---

## שלב 4 — הגדרה בפרויקט

הוסיפו לקובץ `.env`:

```env
FACEBOOK_ENABLED=true
FACEBOOK_PAGE_ID=102938475610293
FACEBOOK_ACCESS_TOKEN=EAAG...הטוקן-הארוך-שלכם
FACEBOOK_API_VERSION=v21.0
```

| משתנה | ברירת מחדל | מה זה עושה |
|---|---|---|
| `FACEBOOK_ENABLED` | `false` | מתג ראשי. `false` = הסוכן מדלג על פייסבוק לגמרי |
| `FACEBOOK_PAGE_ID` | — | מזהה העמוד |
| `FACEBOOK_ACCESS_TOKEN` | — | ה-Page Access Token הארוך |
| `FACEBOOK_API_VERSION` | `v21.0` | גרסת ה-Graph API. אם Meta תוציא הודעת deprecation — עדכנו כאן |

## שלב 5 — בדיקה

```bash
python main.py test-facebook
```

תוצאה תקינה:

```
מחובר לעמוד: שירי הנוסטלגיה של שי (id=102938475610293)
הטוקן תקין. השיר הבא יפורסם גם לפייסבוק.
```

ואז הרצה מלאה:

```bash
python main.py run-once
```

השיר יישלח לטלגרם **וגם** יפורסם בעמוד.

## איך זה מתנהג בפועל

- **תמונה:** אם המחקר מצא עטיפת אלבום מאומתת, הפוסט מתפרסם כפוסט תמונה
  (`/photos`) כך שהעטיפה היא חלק מהפוסט. אם התמונה לא נגישה לפייסבוק, הסוכן
  מזהה את זה ומפרסם אוטומטית כפוסט טקסט במקום.
- **לינקים:** בטלגרם הלינקים הם כפתורים; בפייסבוק אין כפתורים, ולכן הם מופיעים
  כשורות טקסט בתחתית הפוסט.
- **טלגרם קודם:** אם פייסבוק נכשל מסיבה כלשהי, ההודעה בטלגרם כבר יצאה והשיר
  נרשם כמפורסם. השגיאה נכתבת ל-`logs/agent.log` וההרצה ממשיכה — לא מאבדים יום.
- **תיעוד:** מזהה הפוסט בפייסבוק נשמר בעמודה `facebook_post_id` במסד הנתונים,
  לצורך אנליטיקס ב-Phase 4.

## פרסום מתוזמן (Scheduled Posts)

התשתית תומכת גם בתזמון מראש — שימושי אם תרצו להכין שבוע של פוסטים מראש:

```python
from datetime import datetime, timedelta

client.publish(post, publish_at=datetime.now() + timedelta(days=1))
```

פייסבוק מחייבת שהזמן יהיה **לפחות 10 דקות** קדימה ו**לא יותר מ-6 חודשים**;
הקוד בודק את זה מראש ומחזיר שגיאה ברורה במקום לשלוח בקשה שתידחה.

## הרצה בענן (GitHub Actions)

הוסיפו שני סודות נוספים ב-**Settings → Secrets and variables → Actions**:

| Name | Secret |
|---|---|
| `FACEBOOK_PAGE_ID` | מזהה העמוד |
| `FACEBOOK_ACCESS_TOKEN` | הטוקן הארוך |

ה-workflow מדליק את הפרסום לפייסבוק אוטומטית כשהסוד `FACEBOOK_PAGE_ID` קיים,
ומדלג עליו כשהוא ריק — אין צורך לערוך את קובץ ה-workflow.

## פתרון תקלות

| השגיאה | למה | מה עושים |
|---|---|---|
| `Invalid OAuth access token (code=190)` | הטוקן פג או שגוי | צרו טוקן חדש והאריכו אותו (שלב 3) |
| `(#200) requires pages_manage_posts` | חסרה הרשאה | חזרו ל-Explorer, הוסיפו את ההרשאה וצרו טוקן מחדש |
| `Unsupported get request (code=100)` | ה-PAGE_ID שגוי, או שהטוקן שייך למשתמש ולא לעמוד | ודאו שבחרתם **Get Page Access Token** ולא User Token |
| `(#324) Missing or invalid image file` | פייסבוק לא הצליחה להוריד את העטיפה | תקין: הסוכן מפרסם אוטומטית כטקסט במקום |
| הפוסט לא מופיע בעמוד | פורסם כמתוזמן | בדקו ב-**Meta Business Suite → Planner** |
| `test-facebook` מדפיס "פרסום לפייסבוק כבוי" | `FACEBOOK_ENABLED` הוא `false` | שנו ל-`true` |

לוגים מלאים: `logs/agent.log`.
